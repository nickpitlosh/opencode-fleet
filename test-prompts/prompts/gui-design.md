# Domain: User Interaction & GUI Design

Design and prototype a medical patient monitoring dashboard. Requirements:
1. Follow Nielsen's 10 heuristics and WCAG 2.1 AA compliance
2. Design system: color palette (medical-appropriate), typography scale, spacing system, component library with 15+ components
3. Screen layouts: patient overview (grid of 50+ vitals), detail view (trends over 24h/7d/30d), alert management, settings
4. Accessibility: full keyboard navigation, screen reader support, high contrast mode, font scaling
5. Alert system: 3-tier severity with distinct visual/audio cues, acknowledge/escalate workflow
6. Dark mode with proper contrast ratios (≥4.5:1 for normal text)
7. Include Figma-style component specifications with pixel dimensions
8. Write CSS custom properties for the entire design system
9. Prototype in HTML/CSS/JS (no frameworks) demonstrating: real-time updates, alert toast, modal for critical alarms

Deliver: design-system.md, components.css, dashboard.html, dashboard.js, accessibility-audit.md
